# Colleague share links (local preview)

If you run the portal locally, you can share these URLs with colleagues on your network/VPN:

- Main form: `http://<host>:5050/`
- Preview page: `http://<host>:5050/preview`

Direct sample PDFs:

- Graphite sample: `http://<host>:5050/sample-pdfs/sample_graphite`
- Slate sample: `http://<host>:5050/sample-pdfs/sample_slate`
- Aurora sample: `http://<host>:5050/sample-pdfs/sample_aurora`
- Blank template (Graphite): `http://<host>:5050/sample-pdfs/template_graphite`

Replace `<host>` with the machine hostname or IP where the app is running.
