What this tool does

  1. Collect partner profile information via guided form
  2. Accept partner logo upload
  3. Generate branded one-page A4 PDF automatically
  4. Download ready-to-share partner profile in seconds

How to run interactive mode

  1. Run the Flask app from partner_one_pager_portal
  2. Open http://localhost:5050/preview or /
  3. Generate PDFs from the form directly
